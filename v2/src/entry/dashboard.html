What the knowledge base holds

Agents read the index. It is built from your notes by a sync. A fact on disk that the index does not hold yet is marked, and agents cannot find it until the next sync.

How to read the notes
  1. Fact: one block, meaning a paragraph, a list item, a table or a code block. Its fingerprint is a BLAKE3 hash of its words. Case, spacing and sentence punctuation are ignored, so formatting-only edits keep it. A check for the same words looks the fingerprint up, without embedding.
  2. Note: its hash covers its fingerprints in order, each labelled with the headings above it. A sync compares it with the hash the index holds to find the notes that changed. Changing a fact, or moving it under another heading, changes it.

Adding, replacing or removing a fact here changes the note, then syncs, and the changed note lights up. Click any hash to copy it.
