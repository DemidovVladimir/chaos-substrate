The vault

The vault is a folder of Markdown notes, as Obsidian keeps them. chaos-kb reads every visible note and splits it into blocks. It writes only when you call remember, and then it only adds text.

  • facts go to Inbox.md unless you name a note
  • .md is added when a path has none
  • 1 temporary file and 1 rename per write
  • 0 existing bytes changed

A section is a heading and everything below it, up to the next heading of the same or a higher level.

Which note paths are allowed

    
Every path from disk or from an agent is checked by these rules first, so nothing can name a file outside the vault or in a hidden folder. This runs the rules of src/domain/path.rs in your browser.

  

  

    
    

    

  






  

    What sync reads
    
Files the vault skips

    
The vault walks every folder and keeps only what is a note.

  

  
    
    
  • skiphidden namesFiles and folders whose names start with ., such as .obsidian and .chaos-kb.
    • 
    
  • skipsymlinksA linked file or folder is never followed.
    • 
    
  • skipother filesOnly names ending in .md, in any case, are notes.
    • 
    
  • skipnames the path rules refuseFor example a name holding :.
    • 
    
  • skipvery large notesIn the current code, a note over 4 MiB.
    • 
    
  • readbroken textBytes that are not valid UTF-8 are read as replacement characters.
    • 
  






  

    Enforced in code
    
Guarantees

  

  
    
    
  • Only remember writes notes. sync, check and search never change a note.
    • 
    
  • Existing text stays byte for byte. remember inserts its text and one blank line around it; nothing else moves.
    • 
    
  • Never half a note. A write goes through a temporary file, a flush to disk and a rename, and keeps the note's permissions.
    • 
    
  • Nothing outside the vault. Paths are relative with visible segments; a symlinked folder or note, or a folder resolving outside the vault, is refused.
    • 
    
  • No damage to odd files. A note that is not valid UTF-8 is refused, not rewritten.
    • 
    
  • Code is not a heading. A # line inside a code fence never counts as a section.
    • 
    
  • Missing pieces are created. A missing note, its folders and its heading are added.
    •
